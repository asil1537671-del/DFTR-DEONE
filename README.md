# دفتري — دفتر اليومية والتحصيل

تطبيق ويب عربي لإدارة العملاء والديون والتسديدات، مع أرصدة متعددة العملات وتقارير يومية.

## التشغيل المحلي

يتطلب Node.js 18 أو أحدث. شغّل `تشغيل-دفتري.cmd` أو نفّذ `node server.mjs`، ثم افتح `http://127.0.0.1:8765`.

## الدخول والمزامنة

يدعم التطبيق الدخول برابط البريد الإلكتروني ومزامنة بيانات الدفتر إلى Supabase. نفّذ `supabase-schema.sql` واضبط عناوين التحويل كما في [SUPABASE-SETUP.md](SUPABASE-SETUP.md) قبل أول تسجيل دخول.

واجهة إرفاق ملفات PDF غير مفعّلة في النسخة الحالية؛ وملفات PDF المحلية لا تدخل ضمن مزامنة دفتر الحساب.
