# دفتري — دفتر اليومية والتحصيل

تطبيق ويب عربي لإدارة العملاء والديون والتسديدات، مع ملخصات وتحويلات العملات ومرفقات PDF مرتبطة بحساب كل عميل.

يدعم التطبيق زر الرجوع في الهاتف والمتصفح للتنقل بين الشاشات، ويحفظ موضع الصفحة وبيانات النموذج المفتوح عند التحديث.

## تشغيل التطبيق مع حفظ ومشاركة ملفات PDF

يتطلب Node.js 18 أو أحدث. لا يحتاج المشروع إلى تثبيت حزم إضافية.

1. افتح مجلد المشروع في PowerShell أو Terminal.
2. شغّل الخادم:

   ```powershell
   node server.mjs
   ```

3. افتح `http://127.0.0.1:8765` في المتصفح.
4. افتح حساب أي عميل، واختر **إرفاق PDF**. حدّد الملف وتاريخه، ثم احفظه. استخدم **مشاركة** لاختيار تطبيق أو جهة اتصال على الهاتف؛ إذا لم يدعم المتصفح مشاركة الملفات، ينزّل الملف لتتمكن من إرفاقه يدويًا.

يتحقق التطبيق من امتداد الملف ونوعه وتوقيع PDF وحجمه قبل الإرسال، ويعيد الخادم التحقق قبل الحفظ. الحد الأقصى 10 ميجابايت. تحفظ الملفات في `uploads/` وتفاصيلها في `data/documents.json`، ويرتبط كل مستند بمعرّف العميل وتاريخه.

الخادم يستمع على الجهاز المحلي فقط. المشاركة ترسل ملف PDF نفسه عبر قائمة المشاركة في الهاتف؛ إنشاء روابط عامة للتحميل يتطلب استضافة الخادم على خدمة HTTPS.

## البيانات

بيانات دفتر العملاء الأصلية تُحفظ في `localStorage` داخل المتصفح. مرفقات PDF تُحفظ على الجهاز الذي يشغّل `server.mjs`. احتفظ بنسخة احتياطية من مجلدي `data/` و`uploads/` إذا أردت نقل المرفقات إلى جهاز آخر.
