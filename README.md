# دفتري — دفتر اليومية والتحصيل

تطبيق ويب عربي لإدارة العملاء والديون والتسديدات، مع ملخصات وتحويلات العملات.

## التشغيل

افتح `index.html` في متصفح حديث. تُحفظ البيانات محليًا في المتصفح عبر `localStorage`.

## ملاحظات

- لا توجد خدمة خلفية أو مزامنة سحابية مضمّنة.
- احتفظ بنسخة احتياطية من بيانات المتصفح قبل مسح بيانات الموقع أو تغيير المتصفح.
